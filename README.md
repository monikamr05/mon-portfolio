# Monika M R - Personal Portfolio

A modern, responsive portfolio built with **HTML5**, **CSS3**, and **JavaScript** only — no frameworks or build tools required.

## Features

- Dark / Light mode toggle
- Gradient accents and card layouts
- Scroll animations and skill bars
- Education timeline
- Fully responsive (mobile, tablet, desktop)
- Contact form (opens email client)

## How to Run

**Option 1 — Open directly**

Double-click `index.html` in your browser.

**Option 2 — Local server (recommended)**

```bash
npx serve .
```

Then open the URL shown (usually http://localhost:3000).

## Project Structure

```
index.html      → Main page
css/style.css   → All styles
js/main.js      → Theme, menu, animations, form
public/         → Profile photo & favicon
```

## Customization

1. **Profile photo**: Add your image at `public/profile.png`
2. **Content**: Edit text directly in `index.html`
3. **Colors**: Change CSS variables at the top of `css/style.css`
